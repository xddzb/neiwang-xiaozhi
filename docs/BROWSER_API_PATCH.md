# 麒麟 ARM64 浏览器与业务接口离线补丁

适用：现有 R11.3、DSH 0.2.0-rc.2、Linux ARM64、随 APP 的 Node 24 与 Electron。无需重装 APP，不联网安装依赖。Playwright Core 固定 1.56.1，浏览器复用 APP 已有 Electron。

## 安装

退出内网小智和业务浏览器，用原 APP 所属用户（不要 sudo）解压补丁，进入 `Neiwang-Kylin-ARM64-Browser-API-Patch`：

```sh
sh 安装补丁.sh "/完整路径/Neiwang-Xiaozhi-Kylin-ARM64-R11.3"
```

补丁自动接入独立插件管理器、安装浏览器插件，仅补充缺失业务接口文件并增加浏览器登录适配分支。已有同名业务源、连接配置均保留，不覆盖模型/RAG、聊天、任务、工作区或钉钉绑定。安装中断后完全退出 APP，重新执行安装命令；若锁来自中断事务，先执行 APP 根目录 `sh 管理插件.sh recover`。

重启 APP，在“设置 → 业务浏览器与接口”点击打开，亲自登录需要使用的业务系统。可告诉小智：“列出业务接口源”“读取我指定的业务页面，不提交”。

## 恢复范围与登录

组织补丁从本地原始打包脚本和业务脚本中静态恢复 15 项定义：TMS 5、调试 IMS 3、ISU分页 2、AED/ONCE 4、ISU仪表 1；其中缺少 menuCode 的 IMS TCA/TSD 仍禁用。施工 IMS 仍需状态化适配，不宣称恢复为可调用 REST 源。

新增四份无令牌的连接模板，来源为原始基础地址，不复制 Cookie、密码或令牌。已有同名连接不会被自动改为 Playwright。若要让已有连接复用业务浏览器登录，可在本机将其 `browser_session.driver` 设为 `playwright`，`allowed_origins` 设为该系统精确 HTTP(S) origin；保留其他用户配置。ISU仪表仍使用原有独立登录配置，不会被重置或伪装成已登录。

浏览器登录数据保存在本机 `data/business-browser`（采用数据目录覆盖时随之变化），与聊天窗口隔离。只在环回地址开放浏览器调试和带随机令牌的私有会话适配服务，不向模型输出 Cookie。不会读取其他浏览器或其他电脑的登录态。客户端证书、企业浏览器扩展、专用 SSO 仍需组织实机验证。TLS 校验和 Chromium 沙箱不被本插件关闭；系统须允许原有 Electron 运行。

浏览器自动化通过一个 `mcp__browser__automation` 工具提供按需 `help`、标签页、导航、快照、填写、点击、选择、按键、滚动、拖拽和截图。密码由用户输入，提交、审批、发送、删除仍遵守现有授权规则；`confirmed` 只是操作确认参数，不能代替组织管理员权限。没有任意 JS、Cookie 或存储导出工具。

新浏览器由 `config/app.json` 中的 `@neiwang/browser-automation` bundle 启用，旧 `businessBrowser` 字段仅属历史启动器配置，不再是本插件的启用开关。

## 提示词精简

默认把 PTC `tools:sdk` 中全量工具参数声明改为按需 `tool_catalog` 发现。工具仍可调用，审批、安全和业务说明保留，不修改内核。设置页可关闭精简；下一次请求重新组装提示词。设置页展示实际组装字符数，模型 tokenizer 不同，不能把字符数直接称为精确 token 数。不会自动删除已有对话历史或用户技能内容。

实际 R11.3 标准 Agent + 本地合成模型请求对比：系统提示词 48,963 → 8,659 字符，减少约 82%；原生模型工具入口仍只有 `run_code`。精简后的 Agent 已通过目录发现浏览器工具、读取其操作帮助并列出业务接口源。该数字不是对所有用户对话的 token 数承诺。

## 回退

退出 APP，回到补丁目录执行：

```sh
sh 回退补丁.sh "/完整路径/Neiwang-Xiaozhi-Kylin-ARM64-R11.3"
```

应先回退本补丁之后安装的其他插件事务。回退恢复旧会话适配代码，移除本补丁新建且未被用户修改的源文件；已修改的源或连接配置保留，浏览器登录数据也保留。不要手动删除 `data/`。后续只更新浏览器插件代码时可走独立管理器；这次包含接口恢复，应使用完整的补丁安装/回退入口。

本补丁包含内部业务地址与接口定义，仅向组织内交付，不上传 GitHub。GitHub只保留通用插件源码、打包工具和不含私有数据的验证记录。没有访问真实内网接口、发钉钉消息或写表格；模拟验证不能替代真实麒麟和组织业务验收。

技术依据：[Playwright CDP连接说明](https://playwright.dev/docs/api/class-browsertype#browser-type-connect-over-cdp)、[Electron安全建议](https://www.electronjs.org/docs/latest/tutorial/security)。CDP与完整Playwright协议能力有差异，复杂网站仍须按实际业务验证。
