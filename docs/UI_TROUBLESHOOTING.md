# 界面稳定性排查记录

## 用户现象与已确认事实

用户报告内网小智不操作也会左右晃动。桌面快捷方式指向 R9，GitHub 开发源码的变化不会自动作用于该已安装/已运行版本。暂未在维护者隔离测试环境稳定复现同一空闲抖动，不能把未复现的根因写成已证实。

已确认桌面壳每次用随机 session partition，界面偏好和首次提示无法稳定跨启动保留；同时原生菜单由自定义代码主动创建。二者已分别改为 data/desktop 下的持久会话，以及空菜单。

在 125% 显示缩放下记录过分数像素视口宽度。作为边界稳定处理，桌面壳采用内容区尺寸，独立 CSS 限定外层尺寸/滚动边界，阻断子内容对外层宽度的影响，取消三栏网格过渡。此处理没有关闭拖动调整栏宽，也没有修改内核。

## 验证与限制

隐藏窗口验证原生菜单为空、菜单栏不可见；钉钉、AI 表格和模型页可用，合成模型凭据可保存。静置 90 次布局采样只观察到一种宽度组合，没有捕捉到持续左右变化。几何稳定不能排除显卡/合成器层面的视觉问题，也不能替代用户实际窗口验证。

可见界面自动测试已停止；后续同类验证使用隐藏测试壳，不显示/聚焦测试窗口。此前可见测试窗口的反复打开可能干扰桌面观察，因此不以该过程判断用户现场根因。

## 已安装 R9 的应用与回退

只更新了桌面壳和独立品牌适配；配置、聊天、模型密钥、机器人和 DWS 登录数据未参与替换。完全退出并重新打开 R9 后才生效。原文件备份位于维护工程 backups/ui-20261022，未上传 GitHub。

若重启后仍存在，应在同一窗口、同一缩放下继续收集尺寸变化、布局/资源重载和 GPU 合成信息，区分 DOM 布局变化、重载和纯绘制闪动；目前不宣称根因或彻底修复。切勿通过清空用户数据来验证。
