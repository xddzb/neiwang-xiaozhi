内网小智 R10 更新说明
更新日期：2026-10-21
交付平台：Windows x64、麒麟 ARM64

一、内核与配置、扩展解耦
保留官方 DeepSeek Harness 0.2.0-rc.2 内核及完整基础依赖，将启动和桌面适配、品牌、业务插件、部署清单与用户数据分层保存。
core/<版本> 存放官方内核；launcher 管理启动与桌面；config 管理部署配置；extensions 存放扩展；data 和 workspace 保存用户配置、聊天、绑定及工作文件。
官方内核使用 SHA256 基线检查，扩展装配不直接修改官方内核。后续升级可分别处理内核、平台运行时和扩展；仍须验证接口兼容性，不能仅替换 Node 或某个内核文件。

二、核心主体与插件包分装
每个平台分别交付 Core 核心包和 Plugins 插件包，单个文件均低于450MB，满足本次钉钉500MB单文件发送限制，无需分卷拼接。
核心可单独运行，包含完整官方内核、桌面界面、模型对话、文件/命令工具、代码变更查看和基础配置。模型推理仍需用户配置可访问的模型接口。
插件补齐钉钉机器人、DWS AI表格、Python/PyInstaller、Office/PDF/OCR及内网知识库/业务工具。
Windows核心约363.89MB、插件约162.45MB；麒麟核心约356.50MB、插件约154.28MB。精确字节数及SHA256见安装与验证说明。
先解压核心。需要扩展时完全退出APP，将插件包内plugin-pack放到核心目录，运行其中对应平台的安装脚本，再重启APP。
安装器检查平台、版本、文件完整性及冲突，支持同包重复安装，保留已有用户配置、聊天和工作文件；仅解压插件不会启用功能。R10插件不可混装到R9或Win7包中。

三、钉钉机器人接入
采用DingTalk-Real-AI/dsh-dingtalk 0.10.2官方项目连接器，通过Stream长连接将私聊和按策略启用的群内@消息交给本机Agent执行并回复。
设置页提供配置向导、离线诊断和“生成绑定口令”，可直接显示、复制完整/bind命令及有效期，无需为查询口令打开终端。
首次使用需在组织开放平台创建并发布内部应用机器人，启用Stream和相应权限、配置本机凭据，重启APP连接，再在机器人私聊完成管理员绑定。
应用凭据、管理员绑定和群访问策略分别管理。离线检查不等于完成真实消息验收，口令和凭据不写入说明或交付包。

四、钉钉AI表格接入
接入官方DingTalk Workspace CLI 1.0.65的AI表格能力，作为独立插件提供dingtalk_aitable工具及27个允许使用的命令，支持表、字段、记录、视图等操作。
在“设置→钉钉AI表格”完成用户登录/授权，并保存完整corpId:userId执行账号，避免组织和用户混用。组织管理员可能需要先允许CLI访问。
写入默认预览，确认写入须基于明确授权，并查询核对结果。不开放任意命令、shell拼接或外部密钥参数；授权信息留在本机。
表格用户授权与机器人凭据、/bind管理员绑定是不同流程。本次接入不代表覆盖全部钉钉表格产品、DWS命令或宜搭。

五、其他改进
加入PyInstaller 6.22.3，提供python_package及打包入口，支持onedir/onefile和已有输出保护，使用匹配平台的随包Python，无需联网安装依赖。
代码变更查看保留在核心中，绿色为新增、红色为删除/替换；覆盖Agent文件工具产生的记录，不替代Git或所有外部写盘审计。
保留中广核白鹭品牌资源，移除业务浏览器；核心版隐藏尚不可用的钉钉入口及RAG开关。
麒麟核心补齐界面中文字库和bubblewrap沙箱，附许可证、来源及源码。沙箱依赖系统支持用户命名空间，不可用时明确报错，不自动降级为无限制执行。

六、验证范围
已通过：四个压缩包逐文件校验及无用户数据检查；官方内核散列一致；核心和扩展版真实Agent文件读写修改、代码变更、桌面界面；插件平台/完整性检查、重复安装及用户数据保留；两平台DWS官方schema与本地模拟数据操作；PyInstaller实际构建并运行生成程序。
Windows已完成官方钉钉Bridge、本机Agent、模拟回复和一次性绑定链路验证。
实际环境是当前Windows11主机与QEMU Ubuntu20.04 ARM64来宾，尚未替代Windows10及真实麒麟V10实机验收。真实企业授权、组织网络、钉钉消息和业务表格仍需部署后验收。
本次未重建Win7兼容版，Win7不在R10分装验证范围内。
