# 麒麟 ARM64 ISU 浏览器增强与自动登录态补丁 1.4.1

适用：已安装完整离线插件的内网小智 R11.6，官方内核 DSH 0.2.1-rc.3，Linux ARM64、随包 Node 24、Playwright 1.56.1。支持浏览器插件 1.0.0/1.0.1/1.2.0/1.3.0/1.4.0；完整新版 1.4.1 内容一致时无需重复安装。

需要已有 weekly-isu 内置浏览器连接与 isu-instruments 只读 Engine.IO v3 接口定义。缺少配置时检查会停止。本次内网定制补丁只在已有连接的 browser_session 中设置用户提供的 isu_realtime_url 页面入口；保留 verify_tls 和其余字段，回退时恢复原文件。

## 安装

1. 将补丁 tar.gz 和同名 .sha256 文件一起带进内网，在所在目录执行 `sha256sum -c Neiwang-Kylin-ARM64-ISU-Patch-1.4.1.tar.gz.sha256`。
2. 执行 `tar -xzf Neiwang-Kylin-ARM64-ISU-Patch-1.4.1.tar.gz`，进入解压目录。
3. 完全退出小智及内置业务浏览器。使用原安装用户操作，不用 sudo。
4. 执行 `sh 检查补丁.sh "/现有APP绝对目录"`。目录内应有 start.sh、config、runtime 等。
5. 检查通过后执行 `sh 安装补丁.sh "/现有APP绝对目录"`，再正常启动应用。

例如：`sh 安装补丁.sh "/data/内网小智/Neiwang-Xiaozhi-Kylin-ARM64-R11.6"`。请替换为实际目录，不要传入补丁目录。

在内置浏览器完成ISU登录后，直接要求小智按点名查询。查询会刷新已有实时值页面；没有可用页面时自动按配置入口新建页面，并等待本轮捕获。仅自动捕获预置 ISU 域名 /opgview/socket.io/ 的 EIO=3 Token，结合当前 Cookie 使用，无需复制凭据。不登记新接口、不生成 HAR。捕获的 Token 仅存本机进程内存；重启后可按已配置入口自动打开页面；登录过期时仍需用户完成登录。刷新不保证Token值发生变化，session_refresh.token_changed仅报告是否与刷新前捕获值不同，首次捕获返回null。刷新超时不回退旧Token，不循环刷新或自动重试失败业务查询。

## 浏览器操作

- 顶部地址栏显示完整页面链接（含 # 路由），可输入地址跳转或点击复制链接。
- 点击“＋ 新页面”或 Ctrl+T 新建标签页；点击标签切换，× 或 Ctrl+W 关闭当前页。各页共享该浏览器登录环境。
- 点击“开发者工具”、按 F12 或 Ctrl+Shift+I，打开当前业务页面的独立开发者工具窗口；可查看 Network 请求。
- Ctrl+L 定位地址栏，Ctrl+R 刷新。最多同时打开 20 页。
- 小智的浏览器工具新增 new 操作；tabs 仅列业务页面，不含工具栏或 DevTools。

## 保护与回退

补丁不联网下载依赖，不修改官方内核、模型/RAG配置、机器人绑定、接口定义、聊天记录、工作区或浏览器登录数据；已有连接仅更新上述页面入口字段。更新浏览器与业务适配器的运行/离线载荷两份副本及两个通用接口工具，同步插件清单和已有插件登记散列。

修改前自动备份原文件、权限、清单及登记信息。重复安装不重复修改。工具文件不是支持的基线、运行副本/载荷/散列不一致、存在链接或应用仍在运行时拒绝覆盖；不要为通过检查而删除保护信息。

完全退出应用后执行 `sh 回退补丁.sh "/现有APP绝对目录"`，恢复本次补丁前的原文件。若安装意外中断，先执行 `sh 恢复补丁.sh "/现有APP绝对目录"` 再重新检查/安装。备份保存在原 APP 的 extensions/.plugin-manager/transactions 中，请保留。

若此前装过1.2.0 ISU补丁、1.3.0 自动刷新补丁或浏览器1.0.1补丁，先回退本补丁，再回退旧补丁。补丁后手工修改了受影响文件时，回退会停止，避免覆盖修改。

验收使用合成凭据及本地测试服务；真实 ISU 和实体麒麟仍需现场验证。内网定制包含用户指定的组织页面地址，仅用于内网交付，不上传公共仓库；不包含Token、Cookie、密码或接口文档。ISU专用适配器未配置verify_tls时默认跳过证书校验，显式true可恢复。浏览器例外仅适用于已配置ISU的准确HTTPS来源（含端口），其他来源仍校验；不使用全局TLS关闭开关。
