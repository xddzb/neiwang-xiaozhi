# 麒麟内网版：安装后直接使用

本目录的 Internal Core 和 Plugins 已内置固定的模型配置、RAG 配置、本地接口文档及接口源。新电脑不需要旧 APP，不需要迁移，也不需要运行“配置模型”或“配置RAG”。首次启动会自动加载随包配置。

将两份 Internal .tar.gz 和合并安装R11.4.sh 放在同一目录，执行：

```sh
sh 合并安装R11.4.sh "/data/内网小智R11.4"
sh "/data/内网小智R11.4/Neiwang-Xiaozhi-Kylin-ARM64-R11.4/start.sh"
```

目标目录必须不存在；使用普通用户执行。脚本只合并安装，不读取旧 APP，不导入旧配置。两包分别小于500MB，是因为内网钉钉只允许上传500MB以内文件。请在麒麟端解压，保留Linux权限与符号链接。

模型和RAG服务使用内置地址，运行电脑需要能够访问这些内网服务。钉钉账号绑定和登录授权属于账号身份，仍需本人完成；旧 APP 原目录保持不动。

这里的“固定”表示随包预配置，并非将凭据锁死或禁止以后维护。更新固定配置时重新制作组织内部交付包。Internal 含组织私有配置与文档，只在组织内部传递；GitHub Public 包独立提供。
