# 浏览器与业务接口补丁验证

2026-10-24，目标为已有 R11.3 / DSH 0.2.0-rc.2 麒麟 ARM64 离线增量补丁。

- Windows：39 项回归中 36 通过、3 个仅适用 Linux/root 的用例跳过，无失败。
- Ubuntu 20.04 ARM64 / QEMU：在禁用外部网络、仅启用环回地址的命名空间执行 39 项回归，全部通过。
- 真实 ARM64 Electron/Playwright：在同样隔离的网络中，导航、快照引用、密码脱敏、填写、下拉、iframe、截图、滚动、未确认提交拦截及本机合成提交通过；原 Python `business_api` 可通过私有会话桥接读取浏览器的 HttpOnly 登录状态，完成合成只读接口查询，返回结果不含 Cookie。
- 真实 Host/标准 Agent：原生入口保持为一个 `run_code`；精简后通过目录发现浏览器工具、读取帮助并调用原 `business_api list`，返回 15 项恢复的源。设置页入口、数量、精简选项及原主窗口无“编辑”菜单验证通过。
- 正式交付归档实际安装、重复安装、回退通过；模型、RAG、钉钉绑定和工作区合成样本逐字节保持不变。浏览器运行代码与已完成 ARM64 功能验证的候选包相同；另在自有桌面预加载层加入品牌调整。

独立 Electron 页面夹具验证了早期加载标题、32px/18px 主副标题、首页徽标隐藏及 PDF 预览文字保留；真实主窗口设置页正常。品牌夹具使用与应用相同的预加载脚本和对应内核 DOM 结构，并非已在原生麒麟上验收。

减少 40,304 字符，约 82%。这些是本地合成模型实际收到的请求内容尺寸，不是精确 token 数。未测组织 Qwen/DeepSeek 的 tokenizer，也不承诺所有会话都缩减同一比例。只替换生成的 `tools:sdk`，未删除授权、安全上下文或业务规则，也未删用户历史。

## 验证边界

没有接入真实组织模型、Dify、业务系统或钉钉，没有发送消息、写真实表格或执行真实审批。两项缺失 menuCode 的 IMS 源保持禁用，施工 IMS 状态化适配仍未实现。已恢复浏览器功能不代表这些业务系统已登录或已通过真实业务验收。

ARM64 模拟图形测试使用 `--no-sandbox --disable-gpu`，仅用于本地测试进程；补丁正式浏览器不携带这些参数。原生麒麟仍需验证系统桌面依赖、沙箱、证书、SSO 和业务控件。Playwright CDP 与完整协议存在能力差异，未把每个可能的网站行为都视为通过。既有 OCR/WASM 的模拟器异常仍见前次插件管理验证记录，本补丁未修改 OCR。

组织补丁包含私有业务接口定义，仅本地交付，不上传公开仓库。通用源码和不含私有地址的[机器可读验证清单](../manifests/browser-api-validation.json)可用于后续维护。
