## 单独记录的 OCR 运行时异常

首次完整模拟集成包含 OCR，并曾通过；后续以普通用户重复验证时，原有 Tesseract/WASM 过程出现 V8 `WriteProtectMemory` / `WasmTriggerTierUp` 致命错误。隔离重测有成功也有失败，测试用 `--no-wasm-tier-up` 未稳定消除问题，根因尚未确定。没有改动产品默认 Node 参数或 OCR 代码。

最终插件管理集成验收收敛为技能升级/回退、PDF文字解析和配置保留，明确标记 `ocrRun: false`；不把不稳定的重复 OCR 测试计为通过。OCR 在真实麒麟上的稳定性仍需现场验证，此问题不是插件安装器的文件校验结果能够证明或排除的。

机器可读结果见 [验证清单](../manifests/plugin-manager-validation.json)。没有测试真实组织模型/RAG接口、没有发钉钉消息或改表格，也没有声称通过真实麒麟 V10 验收。
